[PARAGRAPH p8]

The devices use different networking interfaces depending on whether I need internet access, file transfer, location services, or a connection to another device.

A. OnePlus Nord CE4 Lite 5G

Wi-Fi: Connects to a wireless router or campus access point. It is useful for browsing, online classes, downloads, and streaming without using mobile data. The exact Wi-Fi generation depends on the phone specification and regional variant.

Bluetooth: Provides short-range wireless communication with accessories such as wireless earphones, speakers, watches, and some file-transfer devices.

[PARAGRAPH p13]
GPS / satellite positioning: Uses satellite navigation signals to estimate the phone’s location. Navigation apps combine location with network data to load maps and traffic information.

[PARAGRAPH p14]
USB Type-C port: Supports wired charging and data connection to compatible computers and accessories. With suitable support and settings, a USB connection can also be used for tethering.

[PARAGRAPH p15]
Mobile hotspot and tethering: Allows the phone to share its mobile-data connection with a laptop or other devices over Wi-Fi, USB, or Bluetooth, depending on the mode selected.

2. Real-time cases of malware attacks in networks (5 marks)

[PARAGRAPH p26]
Malware is software designed to perform harmful actions, such as stealing information, encrypting files, spying on users, or taking control of devices. A network can help malware spread from one computer to another or allow attackers to control many infected devices at the same time.

[HEADING p27]
Case 1: WannaCry ransomware (2017)

[PARAGRAPH p28]
WannaCry was a ransomware worm that spread by exploiting a vulnerability in the [REDACTED: LOC] SMBv1 file-sharing service. Once a vulnerable computer was infected, the malware encrypted files and attempted to spread to other reachable computers on the network. The incident affected organisations in many countries, including healthcare services. It showed that one unpatched computer can become a risk to other systems connected to the same network. The main lessons are to install security updates, disable obsolete SMBv1 where possible, segment networks, and maintain offline or otherwise protected backups.

[HEADING p29]
Case 2: Mirai botnet and the Dyn DDoS attack (2016)

[PARAGRAPH p30]
Mirai targeted Internet of Things (IoT) devices such as routers, cameras, and digital video recorders that used weak or default login credentials. Infected devices were gathered into a botnet and instructed to send large volumes of traffic toward a target. In October 2016, a Mirai-related distributed denial-of-service (DDoS) attack against DNS provider Dyn disrupted access to a number of well-known websites. This case demonstrates that even small devices can be misused as part of a large network attack. Changing default passwords, applying firmware updates, disabling unnecessary remote access, and isolating IoT devices can reduce the risk.

[HEADING p31]
Case 3: NotPetya (2017)

[PARAGRAPH p32]
NotPetya initially appeared to be ransomware, but its destructive behaviour caused widespread disruption. It spread through organisations and used credential theft and [REDACTED: LOC] network mechanisms, including SMB, to move between systems. Many organisations experienced serious operational and financial damage. The incident shows why organisations should restrict administrator privileges, separate important network segments, monitor unusual internal traffic, and test their recovery plans rather than relying only on perimeter security.

[HEADING p33]
How these attacks can be reduced

[PARAGRAPH p34]
Keep operating systems, applications, routers, and device firmware updated.

[PARAGRAPH p35]
Use unique passwords and multi-factor authentication where available; change default IoT passwords.

[PARAGRAPH p36]
Enable a firewall and block unnecessary network services and ports.

[PARAGRAPH p37]
Use network segmentation so an infected device cannot easily reach every other system.

[PARAGRAPH p38]
Keep tested backups separate from everyday systems and practise recovery.

[PARAGRAPH p39]
Avoid suspicious links and attachments, and install software only from trusted sources.

3. Outline of recent technological advancements in networking

[PARAGRAPH p41]
Wi-Fi 7: Wi-Fi 7 adds features designed for higher throughput, lower latency, and more reliable connections. It can benefit demanding uses such as gaming, video collaboration, and augmented or virtual reality. A device needs compatible hardware and a suitable router to use Wi-Fi 7 features.

[PARAGRAPH p42]
5G-Advanced: 5G-Advanced builds on 5G through standardised improvements in performance, efficiency, positioning, and support for more connected devices. It is an evolution of 5G rather than a completely separate generation. Availability of features depends on network operators and devices.

[PARAGRAPH p43]
Early 6G research: Researchers and standards groups are studying the next generation of mobile networking, commonly called 6G. Potential goals include very high capacity, integrated sensing, AI-assisted operation, and improved connectivity in difficult-to-reach areas. These are research and development directions, not services universally available today.

[PARAGRAPH p44]
AI-assisted network management: Machine-learning systems can help operators identify unusual traffic, predict congestion, detect faults, and optimise network resources. Human review is still important because inaccurate alerts or automated decisions can affect users.

[PARAGRAPH p45]
Software-Defined Networking (SDN) and Network Function Virtualisation (NFV): SDN separates network control from packet forwarding, while NFV runs functions such as firewalls and load balancers as software on general-purpose infrastructure. These approaches can make networks easier to configure and scale.

[PARAGRAPH p46]
Zero Trust and Secure Access Service Edge (SASE): Modern network security increasingly checks identity, device health, and access permissions rather than trusting a device simply because it is inside an organisation’s network. SASE combines networking and security services for users and sites in different locations.

[PARAGRAPH p47]
Satellite internet and non-terrestrial networks: Low-Earth-orbit satellite systems and developing non-terrestrial network standards aim to extend connectivity to remote regions, ships, aircraft, and emergency locations where terrestrial coverage is limited.

[PARAGRAPH p48]
Edge computing and IoT networking: Edge computing processes some data closer to where it is generated instead of sending everything to a distant cloud. This can reduce delay for applications such as industrial monitoring, smart transport, and connected healthcare.

Conclusion

[PARAGRAPH p50]
This case study helped me connect networking concepts with devices I use every day. My phone mainly provides cellular connectivity, Wi-Fi, Bluetooth, and tethering, while my laptop also supports wired Ethernet. Real-world malware incidents show that insecure devices and unpatched software can affect an entire network. At the same time, technologies such as Wi-Fi 7, 5G-Advanced, AI-assisted management, and edge computing are improving how networks perform. Good security practices must develop alongside these improvements.
